# Flutter Social Media UI

A responsive social-media interface prototype built with Flutter and Dart. The project focuses on mobile UI development, reusable widgets, screen composition, local session state, and responsive layouts.

## Screens

- Splash screen
- Login
- Registration
- Home
- News feed
- Notifications
- Profile
- Content detail

## Project Structure

```text
lib/
├── models/
├── screens/
├── session/
├── widgets/
├── constants.dart
└── main.dart
```

## Technology Stack

Flutter, Dart, flutter_screenutil, cached_network_image, carousel_slider

## Project Scope

This is a UI-focused academic project rather than a production social network. The current session model is local/demo-based and the project does not use a remote backend API.

## Local Setup

```bash
flutter pub get
flutter run
```
